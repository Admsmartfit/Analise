Instruções de Configuração da API do Gmail

  1. Acesse o Google Cloud Console (https://console.cloud.google.com/).
  2. Crie um novo projeto (ex.: smartfit-etl).
  3. Vá em APIs e Serviços > Biblioteca e ative a Gmail API.
  4. Configure a Tela de Consentimento OAuth (Tipo de usuário: Externo), adicione seu e-mail de suporte e inclua a conta do Gmail que recebe os relatórios como Usuário de Teste.
  5. Crie as credenciais (Credenciais > Criar Credenciais > ID do cliente OAuth), escolha o tipo App para computador (Desktop app).
  6. Baixe o arquivo JSON, renomeie-o para credentials.json e salve-o na pasta app/auth/credentials/.
  7. Execute o assistente interativo: python -m app.cli setup-gmail para autorizar a conta.
